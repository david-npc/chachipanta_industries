# chachipanta_industries
Plataforma web inmobiliaria desarrollada para ofrecer servicios de compra, venta y alquiler de propiedades. Chachipanta conecta a personas con su próximo hogar mediante una interfaz moderna, intuitiva y atractiva, facilitando la búsqueda y visualización de casas, departamentos, terrenos y otras propiedades.
